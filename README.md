# Сайт 231inc — новая версия

Новый дизайн сайта продакшн- и фотостудии **231inc** (Душанбе, ул. Айни, 46).
Исходник — артефакт https://claude.ai/artifact/8HmgjQSPToY4bG9RMV5tYo (чужой аккаунт; его не меняли).
Снимок старой версии и её данные: `../99_Исходники/Сайт_231inc_старая_версия/`.

Готовый сайт — папка `site/`. Это статичные файлы без сервера и без внешних сервисов (шрифты, скрипт и фото свои).
Репозиторий: https://github.com/Abdulaimov/231 (публичный).

## Посмотреть

```bash
node tools/serve.mjs
```

Откроется на http://localhost:8231. Этот локальный сервер сжимает текст и отдаёт видео частями, как настоящий хостинг.
Без Node: `python3 -m http.server -d site 8231` (видео в Safari так может не воспроизвестись).

## Обновить тексты, цены, фото

Всё содержимое лежит в `content.json`. После правки:

```bash
python3 build.py
```

Нужны Python 3.9+ и Pillow 11.2+ (`pip install pillow`), для видео — ffmpeg. Повторная сборка пересжимает только новые фото.

- **Цены на видео** — `pricesText`. Формат как на старом сайте: строка «Название | цена», ниже пункты с «•», пустая строка между пакетами, внизу «Примечание: …».
- **Тарифы SMM** — `smm.plansText` («НАЗВАНИЕ | цена», описание, пункты «Жирное начало. Пояснение», «Результат: …»), `smm.allText` («01. Заголовок» и текст).
- **Команда** — `team`: имя, роль, описание, цена, `works` (все работы по порядку), `featured` (до 3 избранных, как на старом сайте), `showcase` (что показать на главной).
- **Новое фото**: положить файл в `originals/` (имя файла = ключ, например `said-07.jpg` → ключ `said-07`), добавить ключ в `works` нужного автора и подпись в `media` (`"said-07": {"alt": "…"}`).
- **Видео**: файл `originals/<ключ>.mp4`, в `works` записать `"v:<ключ>"`, в `media` указать `"type": "video"`. Видео сжимается до 720p и грузится только по нажатию.
- **Проекты (кейсы)** и **бэкстейдж** — `works` и `backstage` в корне файла (формат старого сайта). Пока они пустые, на сайте этих разделов нет. Как только появятся записи, разделы, фильтр и окно проекта включатся сами.
- **Домен**: когда будет адрес сайта, впишите его в `site.url`, чтобы превью ссылки в мессенджерах и canonical работали с полным адресом.

Шрифты уже подготовлены в `src/fonts/`. Пересобирать их нужно, только если меняется шрифт: `python3 tools/prepare_fonts.py` (нужны fonttools, brotli и skia-pathops).

## Выложить

Залить содержимое `site/` на любой статический хостинг: GitHub Pages, Netlify, Cloudflare Pages или обычный веб-сервер. Файлы с хэшем в имени и фото можно кешировать надолго, `index.html` — без кеша.

## Структура

| Путь | Что это |
|---|---|
| `content.json` | все тексты, цены, команда, порядок фото, подписи к фото |
| `build.py` | сборка: фото → AVIF/WebP/JPEG нескольких размеров, видео → 720p, разметка всех страниц |
| `src/styles.css`, `src/app.js`, `src/router.js` | стили, поведение, маршруты старых адресов (`#prices`, `#p-said` …) |
| `src/fonts/` | Unbounded 500 и Onest 400–600 (латиница и кириллица), слово-логотип в контурах, лицензии OFL |
| `src/logo.svg` | знак 2/1/3 из исходника без изменений |
| `originals/` | оригиналы фото и видео из хранилища старого сайта (48 файлов + 2 портрета) |
| `tools/serve.mjs` | локальный просмотр |
| `site/` | готовый сайт |

### Дизайн и эффекты

- Тёмная «кинозальная» тема из исходной идентичности 231inc: графит `#0B0C0F`, слоновая кость `#EDE9E0`, фирменный вольфрамовый акцент `#E3A857`. Блоки с текстом и ценами — светлые, для ритма и удобного чтения.
- Шрифты: Unbounded (заголовки, как в логотипе) и Onest (текст). Знак 2/1/3 и слово-логотип не менялись, фирменный наклон −11° и контурное «INC» используются как приём.
- **Интро «231»** при первом заходе за сессию: на фоне киноракорда появляются цифры 2, 3, 1, прорисовывается «INC», шторка поднимается. Около 2 секунд, пропускается кликом или клавишей, не показывается при «уменьшить движение» и при заходе по прямой ссылке на раздел.
- **Первый экран как кадр камеры**: затвор, фото «наводит фокус» из размытия, рамка видоискателя с REC и бегущим таймкодом, виньетка. На компьютере фото и рамка слегка следуют за мышью.
- **Лента «Избранное»**: 11 кадров на киноплёнке с перфорацией. На компьютере лента едет вбок, пока прокручивается страница; на телефоне листается пальцем.
- **«Снято вручную и с нейросетями»**: за курсором (или пальцем) сыплются кадры из портфолио, заголовок инвертируется поверх них.
- **Тон «комнаты»**: фон страницы плавно меняется под раздел — тёплый у Saidmukamil, тёмно-красный у NurMuhammad, фиолетовый в студии.
- Фото проявляются шторкой с отъездом камеры, лёгкий параллакс внутри кадров, «расшифровка» подписей, счётчики цен, бегущая строка услуг от прокрутки, курсор «Смотреть», превью работы за курсором, наклон карточек с бликом, «магнитные» кнопки, глитч на ролике ИИ-графики, переходы между разделами шторкой, светлые блоки выезжают «листом», плёночное зерно, полоса прогресса, логотип в подвале прорисовывается.
- Всё на CSS, transform/opacity и IntersectionObserver, без библиотек и WebGL. При «уменьшить движение» эффекты выключаются. Без JavaScript всё содержимое видно, разделы идут подряд.

### Новые функции

- **Референсы**: на любом кадре (и в лайтбоксе) можно нажать ♡ и собрать подборку. Хранится только в браузере посетителя.
- **Сборщик заявки** (кнопки «Обсудить проект», «Собрать заявку», плашка референсов): услуги, автор, дата, имя, комментарий и выбранные кадры складываются в готовое сообщение. «Открыть в WhatsApp» открывает чат студии с этим текстом, «Скопировать и открыть Telegram» копирует текст и открывает чат. **Сайт сам ничего не отправляет** — сообщение отправляет человек в мессенджере. Без выбранной услуги, кадра или комментария кнопки подсказывают, что заполнить.
- **Калькулятор аренды** на странице студии: часы → сумма по ставкам с сайта (1 час — 350, от 2 часов — 300 сомони/час) и кнопка «Забронировать в WhatsApp» с готовым текстом. Подписано, что время и итог подтверждает студия.
- **Приближение в лайтбоксе**: клик мышью приближает кадр в 2,2 раза, движение мыши — рассмотреть детали (на телефоне — обычный щипок).
- **Instagram @231inc и Telegram-канал** (t.me/l231inc — это канал «231», не чат, поэтому запись по-прежнему идёт в чат по номеру) — в меню, контактах и подвале. В оснащение студии добавлена «Циклорама» — из описания их Instagram.
- **Часы Душанбе** в шапке и подвале.

### Что проверено (30.10.2026, локальный сервер с gzip)

- **Скорость** на эмуляции среднего Android, как в Lighthouse (412×823, Slow 4G: 150 мс, 1,6 Мбит/с, процессор ×4), 3 прогона: первая отрисовка 0,54–0,74 с, **LCP 0,59–0,76 с** (фото первого экрана, AVIF 9 КБ), **CLS 0** при загрузке и 0,01 после прокрутки всей страницы, первая загрузка **≈280 КБ**, вся главная со всеми фото, лентой и следом ≈1 МБ. Скрипт 12 КБ, страница 43 КБ в сжатом виде. Компьютер (1350×940): LCP 0,3 с. При первом заходе ещё ~2 с занимает интро — это задумано. Замеры локальные, на реальном хостинге добавится задержка сети до сервера. Для сравнения, вторая (более простая) версия: LCP 0,55 с, первая загрузка 115 КБ.
- **Экраны**: 360×740, 390×844, 768×1024, 1280×720, 1440×900. Горизонтальной прокрутки нет, первый экран с кнопкой помещается.
- **Функции (30 проверок, все пройдены)**: переходы по меню и тизерам, «Назад» с возвратом на прежнее место, кнопка «назад» браузера, старые адреса (`#bts`, `#photo`, `#team`, `#backstage`, `#rent`, `#p-nur`, `#case-…`, `#price-teaser`), копирование телефона и почты, видео грузится только по нажатию, лайтбокс с клавиатуры (стрелки, Esc, возврат фокуса) и свайпом, меню на телефоне, размер кнопок от 44 px, все 525 файлов из разметки на месте, ошибок в консоли и неудачных запросов нет.
- **Доступность**: контраст всех пар цветов по WCAG AA (4,6–16), видимый фокус, переход по «Перейти к содержанию», окна на `<dialog>` с ловушкой фокуса, подписи ко всем фото.
- Новые функции проверены в браузере: интро и его пропуск, лента на компьютере и пальцем на телефоне, след из кадров мышью и касаниями, референсы (сердце на фото и в лайтбоксе, счётчик, сохранение после перезагрузки), текст заявки и ссылка WhatsApp с этим текстом, калькулятор (1 час — 350, 4 часа — 1 200), приближение в лайтбоксе, смена тона фона. Ошибок в консоли нет.
- Реальные заявки и сообщения не отправлялись: ссылки на Telegram, WhatsApp, звонок и почту проверены только по адресам.

### Что нужно уточнить у студии

3. **Фото «девушка у горящей коробки»** (избранное у Saidmukamil) содержит значок «1/10» из карусели Instagram. Лучше прислать чистый оригинал.
4. **Telegram для записи** — в исходнике пусто, а в Instagram указан канал t.me/l231inc, не личный чат. Поэтому запись идёт в чат по номеру телефона (как и было). Если у студии есть ник для заявок, его можно вписать в `contacts.telegram`.
5. **Шоурил, кейсы и бэкстейдж** — в исходнике пусто. Сайт готов их показать, нужны материалы.
6. Таджикской версии в исходнике нет. Если понадобится: Onest поддерживает таджикские буквы, а в Unbounded их нет, для заголовков нужно будет подобрать замену.
